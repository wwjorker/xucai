# 序采功能演示

入口：http://127.0.0.1:5173/ 。先按[安装与运行](安装与运行.md)准备并启动本机环境。以下步骤覆盖普通选购、AI助手和商家方案三条主要流程。

客户 `buyer_demo`，商家 `merchant_demo`，演示密码均为 `XucaiDemo2026!`。请只填写虚构收货信息；不会真实收款或配送。测试会保留需求、聊天和订单记录。

## 1. 先看普通购物

1. 首页按分类或名称找商品，看实物图是否清楚、价格和可购买状态是否好懂。
2. 打开详情，核对规格、商品资料与来源；不同地区或货号的限制应能看到。
3. 加入采购清单，调整数量。到确认页填写虚构地址，先检查商品、数量和金额。
4. 愿意留下测试订单时，再点击确认。到采购订单查看刚才的订单；未支付时可取消。

重点：买普通设备不需要先写需求、等商家方案；操作中不应出现白屏、金额不一致或不知下一步做什么。

## 2. 再用AI助手

1. 登录后点右下角助手，新建对话，说：“预算200元，买四个办公室用的有线鼠标。”
2. 看它是否理解总预算和数量，商品卡能否打开真实详情。条件不够时，继续回答它的追问。
3. 对某个商品说：“这款是什么连接方式？请查资料。”核对回答是否带资料出处；资料不足时不能编造肯定结论。
4. 依据当前展示的卡片说：“第一款要两件，放进采购清单，不要下单。”打开清单核对实际变化。
5. 说：“我要结算。”应进入由你核对的清单或确认入口，不能替你自动下单或付款。
6. 试试拖动标题栏、收起再打开、新建会话、历史切换。生成中可以停止；已经完成的清单操作不会因此撤回。

还可新建对话说“我想买M720”，补充“两件”，再回复“确认”或“取消”。需要删商品时说清单内的型号；清空清单会先询问确认。不同采购批次的预算默认不包含之前已在清单中的商品。每次操作后都可打开清单核对真实数量。

重点：这是有真实业务工具的对话助手。不是每句话都只给文字，也不是让AI自动替你做所有最终决定。回答通过流式输出展示；生成过程中可以停止。

## 3. 最后体验复杂方案与商家端

1. 对助手说明多设备搭配需求，如会议室摄像头、耳机及兼容条件，请它整理复杂采购草稿；也可从首页“复杂方案，请商家协助”手工创建。
2. 核对并保存需求。此时商家才能看到；AI生成草稿本身不会替你提交。
3. 进入商家工作台，使用商家账户，找到这份需求，选择设备、引用资料，核实条件后发布方案。
4. 回客户端，在“我的采购需求”中打开方案并核对。愿意继续时确认订单。
5. 可在客户订单执行演示支付，再到商家订单登记虚构物流，回客户端收货并提交售后咨询，商家记录处理结果。

不确定条件能否满足时，保留待核实，不必为了走完流程硬填“满足”。不再需要的未下单需求可关闭，之后可重新开启，记录不会删除。

## 验证重点

检查推荐条件与商品卡一致、清单数量与金额正确、资料回答有出处，以及客户与商家账户的数据访问边界。停止回复不会撤销已经完成的清单操作。

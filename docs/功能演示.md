# 序采功能演示

先按[安装与运行](安装与运行.md)启动本地环境，再访问 http://127.0.0.1:5173/ 。

客户账号为 `buyer_demo`，商家账号为 `merchant_demo`，演示密码均为 `XucaiDemo2026!`。请使用虚构收货信息；支付和物流为演示流程。操作产生的需求、聊天与订单会保存在本地数据库。

## 1. 普通采购

1. 在首页按分类或名称查找商品，查看价格与售卖状态。未配置商品图片时显示设备示意图。
2. 打开商品详情，查看规格、购买提示与来源资料，留意型号及适用地区。
3. 加入采购清单，调整数量并填写收货信息。
4. 点击“核对订单”，核对商品、数量、金额与收货信息后确认创建订单。
5. 在“采购订单”中查看状态；未支付的订单可以取消。

## 2. AI 选购与资料咨询

先按安装说明启用模型并配置百炼 Key。发送消息会调用模型；普通采购流程不需要模型配置。

1. 登录客户账号，打开右下角 AI 助手，新建对话。例如：“预算200元，买四个办公室用的有线鼠标。”
2. 查看推荐商品与条件说明，点击商品卡可以打开详情。需要补充条件时，继续在当前会话回答。
3. 追问“这款是什么连接方式？请查资料”，查看回答与资料出处。
4. 发送“第一款要两件，放进采购清单”。核对待确认操作中的商品和数量，再回复“确认”；不需要执行时回复“取消”。
5. 打开采购清单，检查商品、数量与金额。需要结算时，通过业务页面核对并确认下单。

也可以直接指定型号，例如“我想买M720”，按提示补充数量后确认。删除商品时说明清单内的型号，清空清单也需要确认。预算默认针对本次新增采购；需要约束整张清单时，可明确说明“整单预算”。

助手支持查看和继续已有会话、新建对话、拖动与缩放浮窗。生成过程中可以停止回复；停止回复不会撤销已经完成的清单操作。

## 3. 商家方案与订单处理

1. 客户从“复杂方案，请商家协助”提交需求，填写设备类别、数量、预算和必要条件；也可让 AI 整理草稿，核对后再保存。
2. 登录商家工作台，打开客户需求，选择设备和资料片段，逐项核实条件并发布方案。
3. 回到客户端，在“我的采购需求”中查看方案、引用依据与待核实项，确认后创建订单。
4. 客户执行演示支付，商家登记虚构物流，客户确认收货。
5. 客户可提交售后咨询，由商家记录处理结果。

不确定的条件保留为待核实。未下单的需求可以关闭或重新开启，相关记录保留。
